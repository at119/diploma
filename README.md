# 🎓 University Admissions Platform

A web application designed to help students explore universities and understand the admissions process.

This project was developed as my **diploma and final project for my Python development courses**. The main goal was to create a platform where students can find information about universities, check admission requirements, and better understand what they need to do to apply.

The entire project was built from scratch using Django and Python.

---

## 🛠️ Technologies

- Python
- Django
- HTML
- CSS
- JavaScript
- SQL / SQLite
- Git

---

## ✨ Features

Here are some of the main features of the platform:

- 🎓 **University Search**  
  Browse and explore different universities and their available information.

- 📋 **Admission Requirements**  
  View the requirements students need to meet when applying to a university.

- 🌍 **University Information**  
  Find information about universities, programs, and admission processes.

- 🔎 **University Filtering**  
  Search and filter universities based on different criteria.

- 👤 **Student-focused Information**  
  The platform is designed to make the admission process easier to understand for students.

- 📚 **Application Guidance**  
  Provides students with information about what is required and how to approach the application process.

---

## ⚙️ The Process

I started the project by planning the main purpose of the platform and identifying the information students would need when searching for universities.

After that, I designed the database structure and created the Django models for universities, programs, admission requirements, and other related information.

I then built the backend using Django and Python and connected it with the database.

Once the main backend functionality was working, I developed the frontend using HTML, CSS, and JavaScript and connected the different pages to the Django backend.

I also implemented the search and filtering functionality so that users could find relevant universities and information more easily.

Throughout the project, I worked on the application from the ground up rather than using an existing template or pre-built project.
